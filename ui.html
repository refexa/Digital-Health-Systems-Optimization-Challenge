Quick mitigation steps for staff (plain language)

These short steps help manage scheduling issues and explain options for patients.

  1. If a requested slot is full: offer the suggested nearby time shown on this page. Say: "We can offer an alternative at [time], would that work?"
  2. For urgent patients: use Priority (staff) to place them earlier. Only use for clinical urgency — this may replace a lower-priority booking.
  3. When demand is high: increase capacity for a busy slot via Set capacity (staff). Explain: "We've increased capacity to accommodate more patients that day."
  4. If many patients are waiting: export the CSV and review recent bookings for reallocation (use spreadsheet sorting by time).
  5. Record decisions: keep a simple log (paper or electronic) of priority preemptions and capacity changes so clinicians understand why slots changed.
  6. Security: keep the staff token private — do not paste it into email or public chat. Use browser Login/Logout to protect token in the session.
