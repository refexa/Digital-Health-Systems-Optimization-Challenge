# Submission Guide

## Local Validation

1. Create and activate a virtual environment.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Start the application with `python scheduler_app.py`.
4. Open `http://127.0.0.1:5000/` to use the dashboard.
5. Run `python simulate.py` in a second terminal to generate sample booking activity.
6. Review metrics at `http://127.0.0.1:5000/metrics`.

## Challenge Deliverable

Submit one PDF, Word document, or presentation containing:

### 1. Healthcare Workflow Analysis

- Current patient journey and booking workflow
- Stakeholders and responsibilities
- Bottlenecks, inefficiencies, and root causes
- Impact on patients, staff, operations, and resource utilization

### 2. Digital Workflow Redesign

- Future-state workflow and labeled diagrams
- Digital technologies and automation used
- Nearest-available slot recommendations
- Priority booking and capacity management
- Operational metrics and reporting
- Patient-centered access and staff oversight

### 3. Impact Assessment

- Expected effects on waiting time and booking efficiency
- Capacity utilization and resource-use measures
- Patient experience and decision-making measures
- Risks, assumptions, mitigations, and evaluation method

The prepared submission is available as:

`refexa_Digital Health System_Challenge.docx`

The filename format for a PDF submission is:

`YourName_Digital Health System_Challenge.pdf`
